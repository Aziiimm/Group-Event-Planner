# Testing Guide

**Run tests Backend**
```bash
cd backend
npm run test
```

**Run tests Frontend**
```bash
cd frontend
npm run test
```

## Run Individual Test Files

### **api.test.ts**
```bash
cd frontend
npx jest __tests__/api.test.ts --runInBand --colors
```

### **supabase.test.ts**
```bash
cd frontend
npx jest __tests__/supabase.test.ts --runInBand --colors
```

### **use-auth.test.ts**
```bash
cd frontend
npx jest __tests__/use-auth.test.ts --runInBand --colors
```
